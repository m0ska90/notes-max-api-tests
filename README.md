# Postman-коллекция для API "Заметки и MAX"

В этой папке находятся файлы Postman для тестирования интеграции с API мессенджера MAX.

## 📂 Файлы
- `Notes-MAX.postman_collection.json` — Коллекция запросов для получения обновлений (Long Polling) и отправки сообщений через API MAX.
- `Local.postman_environment.json` — Шаблон окружения (без секретных данных).

## 🚀 Как использовать
1. Импортируйте оба JSON-файла в ваше рабочее пространство Postman.
2. Выберите окружение `local` в правом верхнем углу Postman.
3. Откройте настройки окружения и заполните реальные значения переменных:
   - `maxToken`: Ваш токен бота в MAX.
   - `maxUserId`: Ваш личный ID пользователя в MAX (чтобы бот мог отправить вам сообщение).
4. Если вы не знаете свой `user_id`, сначала выполните запрос **Get Updates** (предварительно написав боту в MAX), чтобы получить его из ответа.
5. Используйте запрос **Send Message** для проверки отправки сообщения.

**Важное примечание:** API MAX имеет ограничение частоты запросов (Rate Limit) — 30 запросов в секунду глобально и 2 запроса в секунду на один диалог. Пожалуйста, не нажимайте кнопку `Send` слишком часто, чтобы не получить ошибку `429 Too Many Requests`.
