## 🧪 Тестирование API (Postman)

Для тестирования интеграции с API MAX в проект добавлена готовая Postman-коллекция. 

Вы можете найти её в папке [`postman/`](./postman/). Там же находится инструкция по импорту коллекции и настройке переменных окружения (токен бота и ID пользователя).

Это позволяет быстро проверять работоспособность методов отправки сообщений и получения обновлений без запуска основного кода приложения.
